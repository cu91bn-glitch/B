# منصة الموجه الطلابي — وثيقة التشغيل

## نظرة عامة
منصة إرشادية للموجه الطلابي في المرحلة الثانوية، تعمل باللغة العربية (RTL) وتشمل:
- **المراحل 0-3**: الملف الشخصي، البرامج، ملف الإنجاز، سجل الحالات، المتابعة والإنذار المبكر، العيادة الرقمية
- **المراحل 4-5**: محرك الاستبيانات، تحليل النتائج (SWOT، Cronbach's alpha، توصيات)، تقارير PDF
- **المرحلة 6**: رفّ زاد (مراجع، موارد، مؤشرات، برامج)
- **المرحلة 7**: خريطة تغطية المؤشرات (13 مؤشر × البرامج)، مقارنة فصلية، تقرير PDF
- **المرحلة 8**: مراجعة أمنية، خصوصية، أداء، نسخ احتياطي

## التشغيل
```bash
npm install      # تثبيت الحزم
npm run dev      # تشغيل بيئة التطوير
npm run build    # بناء للإنتاج
npm run typecheck# فحص الأنواع
```

## البيئة المطلوبة
- Node.js 18+
- متغيرات البيئة في `.env`:
  - `VITE_SUPABASE_URL` — رابط قاعدة البيانات
  - `VITE_SUPABASE_ANON_KEY` — مفتاح الوصول العام

## قاعدة البيانات (Supabase)
- 20 جدول في مخطط `public`، جميعها مفعّل عليها RLS
- سياسة الوصول: `anon` و `authenticated` (لا يوجد تسجيل دخول — أداة الموجه فقط)
- قيود تفرد على بصمة الجهاز لمنع تكرار الإجابات
- فهارس على: `survey_id`, `indicator_code`, `response_fingerprint`, `created_at`, `indicator_codes (GIN)`

## الخصوصية
- الاستبيانات مجهولة الهوية: لا تُحفظ الأسماء أو أرقام الهوية أو عناوين IP
- الديموغرافيا تقتصر على الصف الدراسي
- تحليل النتائج يتطلب n≥5 مستجيب (إلا إذا تفعّل وضع البيانات التجريبية)
- كشف عبارات الخطر في النصوص الحرة (لم يتم الإرسال، يتم توجيه الطالب للدعم)
- بصمة الجهاز (fingerprint) تُستخدم فقط لمنع التكرار، لا تُعرض في الواجهة

## الأمان
- RLS مفعّل على جميع الجداول
- قيود على رفع الملفات: صور و PDF فقط، حد أقصى 10 ميجابايت
- Honeypot مضاد للسبام في الاستبيانات العامة
- قيد تفرد على (survey_id, response_fingerprint) لمنع الإرسال المتكرر
- لا توجد مفاتيح سرية في كود الواجهة

## النسخ الاحتياطي
- زر «تصدير JSON» في قسم النسخ الاحتياطي ينشئ ملفًا كاملاً بكل البيانات
- يشمل: الشواهد، الاستبيانات، الاستجابات، مراجع زاد، إحصاءات الاستشارة
